# IEEE Research Paper

This folder contains the IEEE double-column conference-paper version of the AI Resume Screening System report.

## Files

- `main.tex` - IEEE conference paper source.
- Figures are reused from `../latex_report/figures/`.

## Compile

Use Overleaf or a local LaTeX installation with IEEEtran:

```bash
pdflatex main.tex
pdflatex main.tex
```

The workspace currently does not have a LaTeX compiler installed, so the PDF was not generated locally.

## Notes

The paper is written as a 12-page-oriented IEEE draft with:

- Abstract and IEEE keywords
- Related work
- Problem formulation
- Full system architecture
- End-to-end input-to-output algorithm
- Mathematical scoring formulation
- Implementation details
- Five benchmark experiments
- Results, discussion, limitations, threats to validity, and future work
